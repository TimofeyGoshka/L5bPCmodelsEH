# L5b pyramidal cell / cortical column model

NEURON model of a layer 5 pyramidal neuron and a thalamic loop, built to test
the apical hypercontextualisation hypothesis (see docs/PROJECT.md).

Tested with Python 3.12.7 and the packages in requirements.txt.

Setup: python -m pip install -r requirements.txt
Compile mechanisms: see docs/PROJECT.md (Phase 0)
Third-party model: thirdparty/hay2011/ (see SOURCE.md there)
